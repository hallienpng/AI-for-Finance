# AI for Finance Hackathon 2025

Система автоматической генерации ответов на финансовые вопросы на русском языке с использованием RAG-подхода.

## Зачем сделан проект

- потренировать полный цикл прикладного NLP/LLM-решения: от подготовки данных до инференса и сабмита;
- проверить, как классический retrieval (FAISS) и rerank улучшают качество ответов;
- собрать воспроизводимый пайплайн, который можно масштабировать под реальные FAQ/knowledge-base задачи.

## Что было реализовано

- построение базы знаний из `train_data.csv`;
- очистка markdown-текста и разбиение документов на семантические чанки;
- генерация эмбеддингов и построение векторного индекса `FAISS`;
- сохранение артефактов индекса (`train_data.index`, `docs.pkl`) для повторного запуска без пересборки;
- гибридный retrieval:
  - keyword prefilter по тегам (ключевые слова извлекаются через LLM),
  - dense search по эмбеддингам (FAISS),
  - финальный rerank документов через отдельную модель;
- генерация итогового ответа LLM на основе найденного контекста;
- батч-обработка вопросов из CSV с промежуточным сохранением результатов сабмита.

## Краткая архитектура пайплайна

1. `train_data.csv` -> cleaning -> section parsing -> chunking  
2. chunk embeddings -> `FAISS` index + `docs.pkl`  
3. вопрос пользователя -> keyword extraction -> prefilter по тегам  
4. dense retrieval (FAISS) -> rerank -> топ релевантных чанков  
5. LLM answer generation -> `submission.csv` (или промежуточный файл)

## Технологический стек

- **Язык:** Python 3
- **Работа с данными:** pandas, numpy
- **RAG / retrieval:** FAISS, langchain text splitters
- **LLM/embeddings API:** OpenAI SDK (через совместимый endpoint хакатона)
- **Асинхронность и устойчивость к rate limits:** asyncio, retry/backoff логика
- **NLP-модели (эксперименты):** sentence-transformers (в отдельном скрипте индексации)
- **Сервисные библиотеки:** requests, python-dotenv, tqdm

## Структура проекта

- `main.py` — основной end-to-end пайплайн (индексация, retrieval, генерация ответов);
- `train_data.csv` — корпус знаний;
- `questions.csv` — входные вопросы;
- `train_data.index`, `docs.pkl` — артефакты индекса;
- `submission.csv`, `submission_ethalon.csv` — результаты сабмита;
- `requirements.txt` — зависимости окружения.
